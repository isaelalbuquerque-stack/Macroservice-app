# Supabase — Macroservice App V5.6

- Edge Function: `consultar-placa`
- Secret obrigatório: `APIBRASIL_TOKEN`
- O app usa somente a Publishable Key do Supabase.
- Nunca publique `APIBRASIL_TOKEN`, service_role ou Secret Key.
- Enquanto `homolog: true`, a APIBrasil devolve dados de homologação. Troque para `false` somente quando estiver pronto para consultas reais e com saldo disponível.
